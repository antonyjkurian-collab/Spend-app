Spend Planner - Android project

Easiest way to get the APK on a phone with no computer setup:
1. Create a free GitHub account and a new empty repository.
2. Upload every file and folder in this project (keep the folder structure,
   including the hidden .github folder).
3. Open the repository's Actions tab. The "Build APK" run finishes in a few minutes.
4. Open the finished run, download the "SpendPlanner-apk" artifact, unzip it,
   and install app-debug.apk on your phone (allow "install unknown apps" once).

With Android Studio: open this folder, wait for Gradle to sync, then
Build > Build APK(s). The APK is in app/build/outputs/apk/debug/.

The app itself is app/src/main/assets/index.html.
